# @pkg-nec/jest-expect

This package extends `@pkg-nec/expect` library with `@pkg-nec/jest-snapshot` matchers. It exports `jestExpect` object, which can be used as standalone replacement of `@pkg-nec/expect`.

The `jestExpect` function used in [Jest](https://jestjs.io/). You can find its documentation [on Jest's website](https://jestjs.io/docs/expect).
